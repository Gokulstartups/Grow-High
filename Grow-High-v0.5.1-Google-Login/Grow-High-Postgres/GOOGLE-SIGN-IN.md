# Google sign-in retired

Grow High now uses email address and password for login. Google sign-in has been removed from the login page and its API endpoints return HTTP 410. Previously stored Google identity link records are retained as historical data and are not used for authentication. Existing email/password users and business records are unchanged.

For accounts originally created using Google sign-in, use the password set during account creation. If you need help accessing such an account, use the account recovery flow.
